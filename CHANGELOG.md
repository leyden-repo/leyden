## 0.1.0 - 2026-11-11

First public release.

- Private markdown knowledge base, created and backed up by `leyden setup`.
- Claude Code hooks: open issues and due reminders at session start, KB search on every prompt,
  capture of finished sessions into the KB.
- Secret redaction before anything is written (rules adapted from gitleaks and detect-secrets).
- Optional team repo: search across both, share an issue as a pull request in the team's format.
- CLI: `doctor`, `tap`, `leak`, `remind`, `sweep`, `export`, `forget` and more.
